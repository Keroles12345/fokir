# Fokir — Personal Portfolio Landing Page

A responsive frontend landing page built to practice modern HTML and CSS layout techniques.

## Highlights
- Responsive navigation and hero section
- About, services, portfolio, and contact sections
- Responsive layout for desktop and mobile screens
- Clean component-style page structure

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Getting Started

```bash
git clone https://github.com/Keroles12345/fokir.git
cd fokir
```

Open the project in your browser, or run it with a local development server.
